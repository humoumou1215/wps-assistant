# pinyin-pro

`pinyin-pro.js` is the unmodified browser distribution (`dist/index.js`) of
`pinyin-pro@3.29.4`, obtained from the npm registry. MIT license: see
`pinyin-pro.LICENSE`. npm tarball SHA-1: `1ceacdf4b453bbc9c6e92aed35cf1b54bb7f12b0`.

Used only for offline full-pinyin/initial matching in the reference picker.
No CDN request, frontend bundler or runtime package installation is required.
