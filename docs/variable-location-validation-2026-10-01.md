# 变量页区域定位验收（2026-10-01）

变量页支持单击表格来源区域与 Render 目标区域，在 WPS 中切换工作簿、工作表，选中区域并滚动到目的地。鼠标单击和按钮的 Enter 键均走 `POST /api/navigate` → 固定 `navigate` RPC，不执行 Transform / Render，不更新变量值或执行时间。

## 位置与兼容

- 来源使用 `Transform.sourceRef`。
- 新建表格 Render 可提供 `targetRef`，保存并通过 `variable.get` 返回；内嵌 Agent 的工具说明与系统提示词包含填写要求。
- 旧 Render 的描述只有一个可识别的 `工作表!A1:B4` 引用时，区域文本成为定位按钮；多个引用、外部工作簿引用和无明确区域的描述不推断目的地。
- 支持绝对地址、中文工作表、引用工作表名与单引号转义；仅接受表格边界内的单一矩形 A1 区域。工作表名含空格时建议使用 `'Sales Data'!A1:B4`。
- 离线定位按钮禁用；工作表被删除、绑定不存在和导航失败在 API / 窗格显示错误。
- 本次只覆盖表格，文字与演示定位尚未实现。
