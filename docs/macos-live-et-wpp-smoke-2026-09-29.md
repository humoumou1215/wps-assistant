Date: 2026-09-29
Platform: macOS / Apple Silicon, Darwin 25.5.0
Test MCP/Add-in WebSocket port: `127.0.0.1:18767` (production MCP remains on `18766`)
Driver: project MCP tools over Streamable HTTP; WPS Add-in code executed inside the real WPS ET/WPP hosts

## Result

**PASS** — one live suite passed against both ET and WPP. It created disposable OOXML inputs under a unique temporary directory, opened them with WPS, waited for the real Add-ins to register, ran `wps.exec` queries and Render mutations, verified read-back, and saved only the disposable copies. The suite exited successfully, restored `addon/main.js`, closed WPS, and removed the temporary directory/state.

The OOXML files are deterministic test inputs generated by `test/wps-live/create-fixtures.py`. They do not contain fabricated API responses: all values below were returned by the real WPS hosts.
