# 选区粒度与引用类型验收

日期：2026-10-01。环境：macOS，本机 WPS JS API Version 12.0。

## 行为

- 当前选区绑定所选文档，跟随其工作表、幻灯片和文字选择变化；发送时通过 Add-in 的只读 `inspect` 请求重新读取一次。同一消息中同一文档的多个当前选区共用该次读取结果。
- 固定选区在引用或点击「固定」时读取当前位置，此后保留工作表、地址、幻灯片/对象和文字范围。固定的是位置，表格值可继续更新。
- 输入框引用标签用 pin 图标切换活动/固定状态：倾斜空心为活动，直立实心为固定；不再显示前导 `@`、类型文字或末尾切换文字。完整文件名和位置保留，文字范围紧凑显示为「3起2字」，完整说明仍保留在预览与消息元数据中。
- PPT 文字只从明确的文本选择读取 `Selection.TextRange`，记录 text/start/length、shapeNames/shapeIds、slide/slideId。对象选择不会继承旧的文字范围。
- Writer 记录 start/end/text/storyType，零长度范围标记为插入点。表格记录不连续 Areas，预览逐个读取，不扩成包含中间未选中单元格的矩形。
- 发送时解析后的引用通过 SSE 同步给 UI 并保存到会话元数据。历史预览使用已保存的位置；「引用以继续」中的当前选区会重新跟随。
- 老版 Add-in 会立即提示重新启动 WPS，避免等待不支持的请求超时。

## 验证结果

基于远端 `main` 的独立 PR 分支中，`npm run check` 和 `npm test` 通过（46 项）。新增覆盖精确文字/插入点采集、选择事件、即时读取、跨工作表跟随、固定引用、同文档一致性、历史保存、多个不连续区域与旧 Add-in 更新提示。

在 ego-browser 的 400 × 900 视口验收：当前与固定选区同时插入；从销售数据!A1:B3 移动到 Summary!D1:D4 后，当前引用更新，固定引用保留原位置；点击「固定」后保存 D1:D4，并显示「跟随」切换入口。标签及其操作按钮的可访问名称同步更新，页面无水平溢出。浏览器截图接口两次超时，后续操作也遇到浏览器响应超时，未生成截图；布局以 DOM 尺寸与可访问树检查。反向切换后的发送流程未完成浏览器实测；发送时重新解析和历史保存由接口集成测试覆盖。

WPS 实机只读验证：新版采集函数返回 Sales!$D$1:$D$4。此前对本机 PPT 实测 `Selection.Type = 3`、选中文字「经营」、Start=3、Length=2；`TextRange2` 返回无关占位值，因此采集不使用它。PPT/Writer 全链路采集和事件另以模拟宿主覆盖；本次实机未执行文档修改。

部署：已构建并重启本机桥接服务，健康检查通过，原文档已重新连接。旧版选区采集插件请求即时选区时返回明确的更新提示；WPS 需重新启动一次以加载新版 Add-in（包括即时选区读取与选择事件）。

- `npm run check` 与独立 PR 分支 `test/ui-view.test.mjs` 的 9 项测试通过；PPT 显示格式检查为 `wra-wpp-hyperlink-probe.pptx›第1页›TextBox 1›「经营」›3起2字`，原始详细标签仍保留类型、起点与长度。
