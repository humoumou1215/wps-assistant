# 完整 API 成员目录

UOS Build 26885 历史枚举，去掉了与 Application 重复的 wpsGlobal / window.wps 别名。对象名是诊断分类，不是执行环境变量；从绑定的 `wpsDocument` 访问文档，选区按引用快照坐标处理。

- **枚举**：仅发现成员和 JavaScript 值类型，不证明当前宿主的签名或效果。函数先核实签名/返回值；COM/WPS 对象只在宿主内访问，提取 JSON 数据后返回。
- **同名探测**：该宿主有同名显式探测，具体结果和验证范围须查对应宿主指南的“显式探测结果”，不代表此对象路径已验证。指南：[表格](spreadsheet.md)、[演示](presentation.md)、[文字](writer.md)。
- ActiveWorkbook/ActivePresentation/ActiveDocument/Selection 属于活动上下文，不能代替绑定目标；文档写入及写方法检查仅放在 Render。
