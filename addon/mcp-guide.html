    连接失败时检查
    • 连接拒绝：确认 Service 正在运行，配置地址与上方显示的端口一致。
    • 工具列表加载失败：选择 Streamable HTTP，使用 /mcp 地址；不要把它配置成旧式 SSE，也不要用浏览器直接打开 /mcp 判断连接状态。
    • 文档列表为空：打开 WPS 文档，确认「WPS MCP」加载项已连接；必要时重新启动 WPS。
    • 客户端未发现工具：确认服务器已启用，重新加载 MCP 或重启客户端，再查看客户端的 MCP 错误信息。
    • 只支持 stdio 的客户端：不能直接使用上述 URL。stdio 会启动新的服务进程，须先停止同端口的后台服务；本引导优先使用 HTTP 复用现有 Service。
    • 隔离网络：MCP 与 WPS 的本地连接可以离线使用；自然语言对话仍要求 Agent 的模型服务在该环境内可用。
