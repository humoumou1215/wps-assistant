## 审计发现与处理

| 问题 | 处理 |
| --- | --- |
| 计划称为“只是换前端”，实际新增模型凭据、Agent 生命周期、网络请求和会话持久化 | 拆分为共享工具层、配置、Agent、HTTP API 和静态 UI，保留八个 MCP 工具与原有只读守卫 |
| 同源并不意味着本机接口自动具备访问校验 | API 检查 Host、Origin、Fetch Metadata、JSON Content-Type；限制请求大小；WebSocket 拒绝外部站点 Origin |
| `sourceRef` 同时写在 Variable 和 Transform 示例上 | 统一落在 `Transform.sourceRef`，作为 `transform.create` 可选参数，不复制两份 |
| 会话历史同时出现默认落盘、inMemory 和 sessions.json 三种描述 | 使用 pi `SessionManager.continueRecent`，只在本服务数据目录 `pi/sessions` 落盘，不另写会话数据库 |
| 只设置 agentDir 和禁用内置工具，仍不足以关闭资源发现 | 显式关闭 extensions、skills、prompts、themes 和 context files；运行时核查只有八个 WPS 自定义工具 |
| 多数 OpenAI 兼容端点不允许工具名包含句点 | 内嵌 Agent 使用下划线别名，映射回相同工具实现；对外 MCP 工具名不变 |
| SDK 默认的配置表达式可能被当作环境变量或 shell 命令 | 密钥经 runtime API 作为字面量传入；额外请求头在模型组成后按字面量设置 |
| GET 配置不应回传密钥，额外请求头也可能含密钥 | 两者都只返回存在标记；空字段保留同端点值；显式清除；更换端点不继承旧凭据；文件权限 0600 |
| GET `/models` 成功不证明模型对话可用 | 连接测试用所选模型发起小额真实请求，20 秒超时，测试失败不保存配置 |
| 用户停止、断流、双击发送、配置切换竞争没有设计 | 增加停止按钮、断流检测、单轮互斥、运行时拒绝换配置、五分钟轮次上限；说明已执行写入不会回滚 |
| 守卫报错重试上限只写在提示词里 | 服务端按轮统计，第三次守卫违规结束轮次，即首次失败后最多修复两次 |
| 原型固定展示连接、示例变量、12% 上下文与伪执行耗时 | 正式页移除全部假数据、演示重播、假 WPS 工作表外壳，只呈现 API 状态与实际调用数据 |
| 活动文档选区被上报给每个打开的文档 | 只给活动文档附选区；引用记录选中时的地址/工作表快照，发送时核对文档仍连接 |
| 重启后的文档顺序可能改变，持久化变量不能只依赖临时注册序号 | state.json 增加路径/文档键到稳定 ID 的映射，注册时持久化；完整文档状态仍只在内存 |
| 并发写 state.json 共用临时文件名，可能 rename 冲突或旧快照覆盖新快照 | 串行持久化、唯一临时文件与原子替换 |
| WebSocket 响应未核对请求所属连接 | 只接受同一连接上未完成 RPC 的响应 |
| WPS pane API 被假定为 Application 成员，且未复用 | 兼容全局 wps / Application、TaskPane / Taskpane、对象/ID 返回值；按入口缓存 pane ID，已在真实 ET 验证 |
| 原型在窄屏下输入框/开关可能被拉宽 | 360×780 界面验证；修正 checkbox 的最小宽度，确认页面无水平溢出 |

原型文件保留为设计参考，不能作为生产入口。正式入口是 `addon/taskpane.html`。

## 实现

- `src/tools.ts`：八工具定义、唯一执行逻辑、执行时间/耗时、原子持久化与稳定文档身份。
- `src/config.ts`：验证、保存、脱敏、同端点凭据保留。
- `src/agent.ts`：pi 0.87.1、隔离资源、八工具映射、引用解析、历史恢复、取消和 SSE 事件映射。
- `src/api.ts`：state / actions / config / config-test / chat 的 HTTP 入口。
- `addon/taskpane.*`：原型视觉风格拆分为无构建依赖的真实页面，含搜索、筛选、代码/值预览、过程详情与错误状态。
- `addon/main.js` / `ribbon.xml`：助手、变量两个入口与任务窗格复用。

## 自动化验证

`npm test`：11 项通过，包含原有只读守卫与 MCP 集成，以及新增用例：

1. Add-in 两个入口重复调用只创建两个 pane，使用 bridgePort 指向正确服务；非活动文档没有误附选区。
2. 静态白名单与穿越路径拒绝、跨站 API 拒绝、JSON 类型校验。
3. 配置数值验证、0600 权限、密钥与请求头脱敏、同端点保留、更换端点清除。
4. **真实 pi SDK** 对本地确定性 OpenAI 测试端点执行八工具完整回路，确认工具列表只有八项。
5. 创建绑定→重算→Render→回读；执行元数据落盘；模拟文档写保护正确返回失败。
6. 守卫上限、模型错误、重复发送、运行期间配置互斥、客户端取消释放 busy。
7. 服务重启恢复会话、值、文档关联，并可再次重写。

模型测试端点和浏览器用的 WPS 文档替身仅存在 `test/helpers/ui-harness.mjs`，没有写进产品页面。测试 API Key 是无效测试字符串，未使用真实付费模型凭据。

## 真人式浏览器验证

通过 ego-browser 在同一 TaskSpace 内实际点击、键盘输入和滚动完成：

- 打开计划原型，核查演示内容与真实产品所需状态差异。
- 无文档/无变量/未配置模型的空状态。
- 设置自定义端点，输入名称、URL、密钥、模型与数值，测试连接并保存；重新打开页面确认密钥不回填。
- `@` 选择选区快照，输入需求并发送，观察工具调用到变量创建、写入完成。
- 变量搜索无结果再清空，展开值和 Render 代码，实际点击重算与单条重写，确认执行时间更新。
- 360px 窄屏设置页，输入无效 Headers JSON，保存被拒且显示明确错误；开关宽度 26px，无整页水平溢出。
- 发送延迟响应并点击停止；发送模拟模型失败，显示错误并保留输入供修正。
- 新页面恢复同一会话历史。

当时的截图覆盖变量与重写结果、配置错误与窄屏布局，显示的文档和模型是明确的隔离测试替身。历史截图已从工作区移除，可从清理前的 Git 提交查看。

一次浏览器页重新加载出现 CDP 超时，已在同一个 TaskSpace 的新页面恢复验证，没有把该次超时算作通过。

## 真实 WPS 验证

在 macOS WPS Build 28496 上操作自动创建的临时文档，生产服务和用户文件未作为写入目标：

- `npm run test:wps-live`：ET 读取单元格/公式、Render 写入公式与格式、回读并保存临时文件；WPP 新增文本框、设置文字与坐标、回读通过。
- 同一真实 ET 测试调用助手入口两次：pane ID 均为 `1`，Visible 为 true；变量入口 pane ID 为 `2`，Visible 为 true。测试收起面板后继续完成文档回归。
- `npm run test:wps-writer-live`：Writer 读取正文与表格、Render 插入并回读、保存关闭临时 DOCX，通过。

任务窗格初次真实测试暴露了全局 `wps` / `Application` 差异；修复后重新运行通过。测试对 API 的“存在”与“实际调用”作了区分。

## 验证边界

- 浏览器会话闭环用确定性本地模型和文档替身；真实 WPS 读写另行验证。没有声称完成付费 DeepSeek 实网验收或所有 OpenAI Responses 服务兼容性验证。
- 真实任务窗格创建/复用当前在 ET 验证；WPP/Writer 文档通道通过，但未逐一点击其 ribbon 面板。
- 旧版绑定没有保存文档身份时无法安全自动关联，需要重新创建；新建绑定已覆盖重启恢复。移动/另存为新路径视为新文档。
- 单会话、文本输入；模型图片能力只是端点元数据，本轮不增加图片上传、多会话或外部 Agent 事件镜像。
- 只读守卫沿用既有设计，是静态约束，不是操作系统安全沙箱。
